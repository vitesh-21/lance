# Stock Management System

## Description
This is a web-based Stock Management System built using HTML, CSS, and JavaScript.

## How to Use
1. Open the home page: [login.html](login.html)
2. Navigate to other pages from the homepage
3. View documentation: [system_documentation.pdf](system_documentation.pdf)

## Code
All HTML, CSS, and JS files are available in this repository.  
Your lecturer can click any file to view the coding work.

## Pages
- login.html – Home page
- admin.html – Admin dashboard
- sales.html – POS system
- login.html – Login page
- register.html – User registration
- forgot-password.html – Password recovery

## Note
This project uses JavaScript only (no backend). Data is stored in browser storage.
