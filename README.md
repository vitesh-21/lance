# 🚀 Stock Management System

## 📌 Description
This is a web-based Stock Management System built using **HTML, CSS, and JavaScript**.  
It allows users to manage products, perform sales (POS), and handle user registration — all in the browser using localStorage.

---

# 🚀 STEP 1: Access the Live System

Open the live system here:  
👉 [Stock Management System Live](https://veshka.ct.ws)

All pages are accessible from the **home page** (`index.html`):

- Login  
- Register User  
- Admin Dashboard  
- POS System  
- Forgot Password  
- System Documentation
